# Antigravity APK Project Contents

This folder contains the complete contents extracted from the uploaded Android APK, plus the original APK.

## Structure

- `original.apk` — original uploaded APK
- `apk_contents/` — every file and directory contained inside the APK

## Important

An APK is a compiled Android application. It does not normally contain the original Android Studio project files such as `build.gradle`, Kotlin/Java source files in their original form, or the original project structure. Those cannot be reconstructed exactly from an APK alone.

The `apk_contents` directory preserves the APK's actual packaged files, including DEX bytecode, resources, native libraries, assets, and metadata.
